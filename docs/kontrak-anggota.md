# Kontrak Kerja & Kesepakatan Tim - Yard Management

## 1. Pembagian Tugas Branch
* Anggota 1: `feature/node-stack` (Membuat Node & Stack)
* Anggota 2: `feature/queue` (Membuat Queue)
* Anggota 3: `feature/yard-manager` (Membuat Yard Manager)
* Anggota 4: `feature/logger` (Membuat Logger sistem)
* Anggota 5: `feature/main-menu` (Membuat Menu Utama)
* Anggota 6 (Ketua): `feature/integration` (Integrasi & Dokumentasi)

## 2. Aturan Commit Git
Setiap melakukan *commit*, wajib menggunakan format konvensional:
* `feat:` untuk penambahan fitur baru.
* `fix:` untuk perbaikan eror/bug.
* `docs:` untuk perubahan file dokumentasi.
